WebKit misses the T15 render budgets that Chromium meets. On CI's Playwright WebKit:
1 MB + 20 Mermaid takes 5038 ms with a 1143 ms task, and 100 KB takes 718 ms. Some
step of the chunked render is not sliced in WebKit. Profile on a machine with WebKitGTK,
fix it, and make the WebKit timing bounds in `e2e/perf.spec.ts` assert again (remove the
`budget()` report-only branch). The gate sets `WEBKIT_BUDGETS=1` so it asserts them meanwhile.

## Location
frontend

## Tests
`test_render_1mb_within_budget_no_long_tasks` and `test_render_100kb_within_budget_no_long_tasks`
in `e2e/perf.spec.ts` pass on the `webkit` project with the timing bounds asserted.

## Acceptance gate
Metric: `render_ms_1MB <= 1500 and longest_task_ms <= 200 on WebKit`.

```bash
npm run build && WEBKIT_BUDGETS=1 npm exec -- playwright test e2e/perf.spec.ts --project=webkit
```
